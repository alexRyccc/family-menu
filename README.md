# 🐱 猫家点菜 v3.1 — Apple 温暖科技风

家庭共享的日常应用：包含点菜、记事本、宠物护理、推荐清单和家庭投票，可在局域网或经 cpolar 临时发布到公网。

## ✨ 功能一览

- **🐱 猫猫家族人物** — 首次进入点击头像即可选择身份,支持一键新增家庭成员(18 种头像可选)
- **🔄 随时切换家人** — 顶栏显示当前用户,点击即可切换身份,无需重新打开页面
- **🥘 116 道精选菜品** — 覆盖家常菜、海鲜、汤羹、面食、甜品饮品和多国料理
- **🔍 分类筛选 + 搜索** — 横向分类 chips 快速切换,搜索支持中文输入法(拼音组词不打断),带一键清除
- **🍚/🍽️ 中饭、晚饭** — 两个时段独立安排
- **🔔 实时通知** — 有人选菜/换菜时,所有在线家人**实时收到**通知(声音+提示+动态流,新消息带 NEW 高亮),SSE 推送 + 25s 心跳保活
- **❤️ 收藏 + 收藏筛选** — 每人可收藏爱吃的菜,一键只看收藏
- **🎲 摇一摇** — 选择困难时随机帮你点一道菜,可"换一个"重摇,加载失败可重试
- **📅 本周安排** — 查看最近 7 天全家人的安排记录
- **⚙️ 管理菜品** — 添加菜品(名称/分类/描述/图片URL)、两步确认删除(防误删)
- **🌓 深色模式** — 自动跟随系统,支持手动切换,同步浏览器主题色
- **📱 Apple 温暖科技风** — 大留白、精致卡片、柔和阴影、流畅动画(卡片入场、摇骰子、主题旋转、骨架屏 shimmer、图片加载微光)
- **🛡️ 健壮性** — 加载失败显示重试 UI、断网提示并自动重连、按钮防连点、弹窗支持 Esc/焦点圈定、触控目标 ≥44px

## 🚀 启动

```bash
cd family-menu
npm install        # 首次运行执行一次
npm start          # 启动服务
```

启动后控制台会显示访问地址,例如:

```
本机访问:   http://localhost:3000
局域网访问: http://192.168.1.9:3000
```

**其他家人**在同一 WiFi 下,用手机浏览器打开 `http://192.168.1.9:3000` 即可使用。

## 🌍 公网访问(可选)

使用 [cpolar](https://dashboard.cpolar.com/signup) 内网穿透,可让**不在同一 WiFi** 的家人朋友也能访问:

```bash
# 1. 安装 cpolar 后绑定账号(只需一次)
cpolar authtoken <你的authtoken>

# 2. 启动隧道(映射 3000 端口)
cpolar http 3000
```

启动后访问 cpolar 面板 `http://localhost:4040/`,页面源码的 `window.data` 中可看到公网地址,形如 `https://xxxx.r16.vip.cpolar.cn`,把这个链接发给家人即可。

也可直接运行一键脚本:

```bat
start.bat           # 启动服务 + cpolar 隧道
setup-tunnel.bat    # 绑定 authtoken + 启动隧道
```

> 注意:cpolar 免费版带宽较慢,大量图片首次加载需要十几秒(已做懒加载,滚动到才加载);免费域名重启隧道后会变化。

## 📝 使用说明

1. 打开网页 → 点击你的猫猫头像(或"新增家庭成员"建一个新身份)
2. 选择 **🍚中饭** 或 **🍽️晚饭**
3. 浏览菜谱,点击菜品卡片的 **"选这个"**
4. 确认选择 → 家人实时收到通知,主页动态流更新
5. 拿不定主意就点 **🎲 帮我选**(摇一摇随机选菜)
6. 点顶栏头像可 **🔄 切换家人**;点 ⋯ 可进入管理/历史/通知设置

## 🔔 通知系统

家人点菜后,可自动发送**邮件**或**短信**给指定人员(如不在家的家长)。

### 配置入口
进入页面 → 点右上角 `⋯` → `🔔 通知设置`

### 添加通知人
在"添加通知人"区域填写:
- **名称**:如"妈妈"、"爸爸"
- **邮箱**:接收邮件通知(可选)
- **手机号**:接收短信通知(可选)
- 至少填写邮箱或手机号之一

### 配置邮件服务(SMTP)
| 字段 | 说明 | 示例 |
|------|------|------|
| SMTP服务器 | 邮件服务商地址 | `smtp.qq.com`(QQ) / `smtp.163.com`(163) / `smtp.gmail.com` |
| 邮箱账号 | 发件人邮箱 | `your@qq.com` |
| 密码/授权码 | SMTP授权码(非登录密码) | QQ邮箱需开启SMTP获取授权码 |

### 配置阿里云短信
| 字段 | 说明 | 获取方式 |
|------|------|----------|
| AccessKeyId | 阿里云访问密钥ID | [RAM控制台](https://ram.console.aliyun.com/manage/ak) |
| AccessKeySecret | 阿里云访问密钥 | 同上 |
| 短信签名 | 短信前缀 | [短信服务控制台](https://dysms.console.aliyun.com/)申请 |
| 模板CODE | 短信模板编号 | 同上,模板内容需含 `${name}` `${dish}` `${meal}` |

### 短信模板示例
在阿里云申请模板,内容如下:
```
【猫家点菜】${name} 的${meal}想吃「${dish}」,请准备食材!
```

### 测试通知
配置完成后,点 **📤 发送测试通知** 验证是否生效。

## 🧰 数据维护

```bash
npm test             # 单元与接口测试
npm run check        # 语法检查 + 全部测试
npm run db:check     # SQLite integrity_check + foreign_key_check
npm run db:backup    # 创建一致性 SQLite 备份
npm audit --omit=dev # 生产依赖漏洞检查
```

服务每次启动会先创建 SQLite 一致性备份，并保留最近 10 份。备份只写入本机 `data/backups/`，系统没有公网下载数据库的接口。

## 🔧 常见问题

- **手机打不开?** 确认手机和电脑在同一 WiFi;检查 Windows 防火墙是否放行 3000 端口
- **端口被占用?** `PORT=8080 npm start` 换端口
- **想让外网朋友访问?** 见上方"公网访问"章节,用 cpolar 内网穿透即可
- **开机自启**:将 `npm start` 做成开机启动任务(任务计划程序)即可
- **重置数据**:删除 `data/family.db` 后重新 `npm start`(首次启动自动建表),再运行 `node seed.js` 恢复默认菜品

## 🛡️ 安全说明

按当前家庭使用约束，本应用不设置账号、PIN 或个人登录。联系人和通知配置接口已脱敏，上传、短信、删除及配置操作也有限流和校验，但**任何知道公网地址的人仍可读取家庭内容、伪装家庭成员并修改数据**。不要公开传播 cpolar 地址；不用时关闭隧道，并定期运行 `npm run db:backup`。完整说明见 [SECURITY_AND_OPTIMIZATION_AUDIT.md](SECURITY_AND_OPTIMIZATION_AUDIT.md)。
